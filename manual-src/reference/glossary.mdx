---

Use this list to familiarize yourself with the vocabulary of FlowJoe.

---

### Flow
The primary document workspace in FlowJoe. A Flow contains a tree structure, node metadata, summaries, tag lists, and references. It corresponds to a single project file.

### Node
A single unit in a Flow's hierarchical tree outline. Nodes are living containers that contain notes, themes, summaries, and media galleries.

### Slot
A single card or cell inside a gallery. Slots hold image previews, audio players, web links, or editable spreadsheet widgets.

### Stack
A collection of multiple media files layered inside a single gallery slot. Stacks allow you to organize file revisions or design variations without cluttering the screen.

### Meaning
The metadata layer (notes, summaries, tags, and context summaries) that captures the intent of your project outline.

### Joe
FlowJoe's AI assistant. Joe communicates via the Chat panel and suggests tree changes through proposal cards.

### Flow map
The name-and-id outline of the tree that Joe is given on a send — nodes, slots, and stack items, plus the Flow Summary, the Theme-menu looks he can set, a node's own look, and a slot's canvas color or lines when it has them. Not file contents. Controlled by **Limit map to my location** and **Omit entire flow map**. See [Token usage with Joe](/joe/token-usage).

### Token bar
The segmented meter at the bottom of the Joe panel showing how this send would use the model's context window. **Flow map**, **Location**, and **Slot data** are separate slices.

### Proposal Card
A chat card that displays proposed tree or gallery changes from Joe. Changes are only applied when you click Approve.

### Virtual Gallery
A read-only gallery view compiled dynamically from tag queries or search results across all nodes.
