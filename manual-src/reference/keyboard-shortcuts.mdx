This page follows the **Keyboard Shortcuts** legend in the app (tree toolbar **K**, status bar **Shortcuts**). A short **Also useful** section at the end lists a few extra keys that are real in the product but not every row in that legend.

> [!IMPORTANT]
> **Open Joe:** `Cmd+Shift+A` / `Ctrl+Shift+A` toggles the Joe chat panel (open / minimize to a floating pill / restore). `Ctrl+J` copies node JSON — it does **not** open Joe. **New node:** `N` / `Ctrl+N` (not Enter or Tab). On Mac, `Cmd+N` is **New Flow**, not add node.

## Tree

| Hotkey | Action |
| :--- | :--- |
| `Ctrl+F` | Tree search |
| `Q` | Query by tags |
| `N` / `Ctrl+N` | Add node (child of the selected node, or a root if none is selected). |
| `Ctrl+P` | Unlock private nodes |
| `↑` / `↓` | Previous / next visible node |
| `←` / `→` | Collapse / expand (or previous / next node when already collapsed/expanded as appropriate) |
| `Space` | Toggle node collapse |
| `+` / `-` | Expand / collapse selected node |
| `Shift+=` | Expand all nodes |
| `Shift+-` | Collapse all nodes |
| `/` or `\` | Hide / show tree |

There is **no** Enter / Tab / Insert shortcut for creating siblings or children. Creating a node is **`N`** (or **`Ctrl+N`**).

## Rich-text editor

These apply inside the [rich-text editor](/reference/rich-text-editor) — Node Summary, Flow Summary, slot Preview notes, and gallery slot/stack notes. They mirror the in-app **Keyboard Shortcuts & Formatting Guide** on the editor toolbar.

| Hotkey | Action |
| :--- | :--- |
| `Cmd/Ctrl+B` | Bold |
| `Cmd/Ctrl+I` | Italic |
| `Cmd/Ctrl+U` | Underline |
| `Cmd/Ctrl+Shift+X` | Strikethrough |
| `Cmd/Ctrl+Shift+H` | Highlight |
| `Cmd/Ctrl+K` | Add / edit hyperlink |
| `Cmd/Ctrl+Alt+1` / `2` / `3` | Heading levels |
| `Tab` / `Shift+Tab` | Indent / outdent a list item |
| `Cmd/Ctrl+Z` | Undo (50-level, persistent) |
| `Cmd/Ctrl+Shift+Z` | Redo |
| `Cmd/Ctrl+F` | Find & replace (Summary and Preview only) |
| `/` | Slash command menu (at a word boundary) |
| `:` | Emoji menu (at a word boundary) |
| `Escape` | Finish editing a gallery note (closes an open `/` or `:` menu first) |
| `Cmd/Ctrl+Enter` | Finish editing a gallery note; Save in the Summary views |

There are **no** text-alignment shortcuts — `Cmd+Shift+R` collided with the browser's hard-reload, so that set was removed. Use the toolbar's alignment dropdown.
