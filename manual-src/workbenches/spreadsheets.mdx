The **Spreadsheet Workbench** is an interactive, editable island powered by Univer Sheets. It lets you manage tabular data directly alongside your outlines and research notes.

---

## Creating & Importing Spreadsheets

- **New Spreadsheet:** Click **Add Slot** (or **Add First Slot** on an empty node) in the gallery and select **New Spreadsheet**. This initializes an empty slot running the Univer Sheets engine.
- **Importing Files:** Drag and drop `.csv`, `.tsv`, `.xlsx`, `.ods`, or `.xls` files directly onto the gallery. FlowJoe turns each one into an editable spreadsheet slot automatically (there is no prompt), and keeps your untouched original file hidden behind it so you can download it again.

- **Formulas & Math:** Supports standard spreadsheet formulas (SUM, IF, etc.).
- **Multi-Tab Sheets:** Add, rename, and delete multiple tabs inside a single spreadsheet slot.
- **Formatting:** Edit font styling, backgrounds, borders, alignment, and column widths.
- **Exporting:** Download the sheet from the slot's menu. It saves in the same format you imported (`.csv`, `.tsv`, `.xlsx` or `.ods`); a new spreadsheet, or an imported `.xls`, downloads as `.xlsx`.
- **Appearance:** The spreadsheet always uses a light look, even when the app is in a dark theme.

## Import and export limits

Treat imported spreadsheets as editable copies focused on values, sheets, and basic formulas. Charts, pivot tables, macros, and advanced formatting are not preserved. Use **Download Original** for the unchanged source, especially for complex workbooks or legacy `.xls` files. CSV and TSV downloads contain one sheet. Very large sheets and long cell text can be cut down during import; use **Download Original** for the complete source.

**Download Original** in the slot's menu returns the untouched imported file. Its filename adds `_orig` before the source extension, such as `Budget_orig.xlsx`, so you can distinguish it from the edited copy. It stays hidden behind the single editable slot.


## AI Access & Interactions

Joe and external terminal agents can read spreadsheet content using the `get_island_content` tool.
- **Analysis:** Ask Joe questions like *"Summarize the total budget in the budget spreadsheet"* or *"Find the outliers in this CSV slot."*
- **Write-back:** Joe can set the value of a single cell at a time (for example *"Put 1200 in B3"*). He does not write formulas, change formatting, or add rows and columns.

> [!NOTE]
> **Resource Isolation:** The spreadsheet workbench only loads its UI dependencies when you open it, keeping the rest of the gallery fast and lightweight.


Joe can list the sheets and read a specific range, such as A2001:C2050, then continue through larger results in pages. He reports which cells were actually read; stored formulas do not prove a fresh calculation.


The Spreadsheet file-type badge appears beside the Preview title, leaving the editor toolbar clear.


## Saving and retrying

While editing, press **F6** (or **Ctrl+F6**) to return to Preview's **Close** control. This moves keyboard focus without closing the spreadsheet. **Tab** continues to navigate cells, **Escape** keeps its normal editor action, and autosave continues as usual. The editor stays out of the way after you leave it, even if a cursor movement was still finishing. You can use Tab to return to the workbench controls or click the editing area to continue typing.

Closing Preview or moving to another stack item waits for your edits to save. If saving fails, the editor stays open with your draft. Once storage is available again, retry **Close**, **Save**, or the stack move without retyping your changes. An earlier autosave finishing does not cancel that retry: your latest changes still need to save. Keep the editor open until saving succeeds. Preview also waits for your latest edit when an earlier autosave is still finishing; it stays open until that edit is saved.

Closing the desktop window or quitting FlowJoe also waits for your editor to save. If saving cannot be confirmed, choose **Stay open** to keep your draft, or **Retry save** once storage is available again. **Close anyway** or **Quit anyway** leaves without confirming the save and may lose your unsaved changes.


## Toolbar names

Accessibility tools can identify the **Font**, **Font size**, **Range / Defined names**, **Add sheet**, **Open sheet menu** and **More** controls. The built-in editor currently uses English for these controls, even when FlowJoe uses another language. These names do not change how you edit cells or format text.

## Mac screen-reader access

Screen-reader reading and editing of cell values is not yet verified on Mac. Current accessibility checks found that the built-in editor exposes toolbar controls but does not expose the tested cell values through the Mac text-reading interfaces checked. This remains an open accessibility limitation. **F6** still moves focus from the editor to Preview’s **Close** control.
