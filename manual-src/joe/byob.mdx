**Bring Your Own Brain (BYOB)** lets you choose the intelligence behind Joe. Use your own provider API key, or connect a supported command-line assistant you already use. Your workspace lives locally; the context needed for an AI request goes to the chosen provider.

A command-line tool, or **CLI**, is an app you run by typing commands in a terminal. FlowJoe can use some of these tools behind the scenes, so you keep talking to Joe in the familiar chat panel.

## Why BYOB?

* **Your account, your usage:** API brains use your provider key and its usage charges. CLI brains use that tool’s account, plan, and limits. FlowJoe adds no markup to either connection. How much context you send affects usage; see [Token usage with Joe](/joe/token-usage).
* **Model Choice:** You choose exactly which model drives Joe—whether you want the speed of a lighter model or the reasoning of a frontier model.
* **Privacy & Control:** Owner requests go from your desktop to the selected provider or installed tool, rather than through a FlowJoe AI service. Shared guests use the owner’s authorized connection; they do not receive its credentials.

---

## 🔒 API Key Storage & Fallbacks

FlowJoe uses a multi-tier storage design for your keys to balance security and convenience:

* **Desktop storage:** Supported keys are encrypted using your operating system’s secure-storage service when available and saved in FlowJoe’s app data. A failed or weak service cannot silently save a new key as plain text. Failed reads and saves preserve an existing saved key; you can explicitly remove it. Standalone browsers still save keys in local browser storage as plain text; session-only storage is not yet available.
* **Export choice:** Keys are excluded from portable exports by default. You can explicitly include an OpenAI key, so review that checkbox before sharing a package.

## Configuring Your AI Brain

To adjust your model config:
1. For an API brain, add its key in **Settings → APIs**. For a CLI brain, install and sign into its tool first, as described below.
2. Click the model settings button inside the Joe panel — or the brain name in the status bar — to pick the brain behind Joe:
   - **OpenAI models (API key):** **Sol 6.1**, **Luna 6** (the default), **Sol 6**, and **Astra 6**, plus **Luna**, **Terra**, and **Sol** from the GPT-5.6 family.
   - **Anthropic API:** **Claude Fable 5.1**, **Claude Opus 5.5**, **Claude Sonnet 5.5** and **Claude Haiku 5.5** use your own Anthropic API key. This is separate from a Claude Code login: you can have both.
   - **xAI API:** **Grok 4.7** uses your own xAI API key. This is separate from a Grok terminal login.
   - **Gemini API:** **Gemini 3.8 Flash** and **Gemini 4 Argon** use a separate Google Gemini API key. See setup below.
   - **CLI brains (no API key):** route Joe through an agent CLI you have already installed and signed into on your own machine — **Fable 5.1**, **Opus 5.5**, **Opus 5**, **Sonnet 5.5**, **Sonnet 5**, **Haiku**, **Grok**, **Antigravity (4 Argon)**, **Antigravity (3.8)**, **Codex (6.1 Sol)**, **Codex (6 Sol)**, **Codex (6 Luna)**, **Codex (5.6 Sol)**, **Codex (5.6 Terra)**, **Codex (5.6 Luna)**, or **Codex (6 Astra)**. CLI installation and sign-in belong to the owner’s desktop. Authorized browser guests use a supported, isolated version of that selected owner CLI through Joe; they do not install it or receive its credentials. Antigravity is currently available only to the owner.
   - **Temperature and response length are managed automatically per model** — there is no manual temperature dial, and GPT-5.6 / GPT-6 models run at their fixed default temperature.

### How the brain menu is arranged

Joe's brain menu groups the brains by company: **OpenAI** first, then **Anthropic · Claude**, **xAI · Grok** and **Google · Gemini**. Each line says how it connects:

* **· API key** — it uses the key you saved in **Settings → APIs**.
* **· Claude Code login ✓**, **· Codex login ✓**, **· Grok login ✓**, **· Antigravity login ✓** — it uses a terminal tool you are signed into.

**More dollar signs mean a more expensive AI choice:** `$` is the lowest-cost group and `$$$$` is the highest. These symbols help you compare choices; they are not the price of a message. **Plan** means usage counts toward the account you signed into. See [What the dollar signs mean](/joe/token-usage#what-each-brain-costs).

A company you have no key for shows one dimmed line instead of one line per model, for example **Grok 4.7 — needs an xAI key**, **Gemini — needs a Gemini key** or **OpenAI — needs an OpenAI key**. Once you save that key, the line opens up into the company's models. The brain list in the status bar shows the same brains in the same order; under each API-key brain it shows the account and the start and end of the key, and a company without a key reads **Needs an … API key**.

### Where to get an OpenAI key

Create one at [platform.openai.com/api-keys](https://platform.openai.com/api-keys), then paste it into **Settings → APIs → OpenAI API Key**. Keys start with `sk-`. You pay OpenAI directly for what you use; FlowJoe never takes a cut and never sees the key.

### Set up Gemini chat

Open **Settings → APIs → Gemini API Key**, paste a key from [Google AI Studio](https://aistudio.google.com/apikey), choose **Test**, then **Save**. A successful key test does not give the project an allowance for every model. Select **Gemini 3.8 Flash** or **Gemini 4 Argon** in Joe’s brain picker. Both use the same key. Gemini 4 Argon is Google's larger model; a free Gemini key has no Gemini 4 Argon allowance, so use a key whose Google Cloud project has a paid Gemini API tier and Argon quota. Either one supports chat and writing assistance. This connection can read permitted Flow content and propose Flow, memory and task changes through the existing approval cards. It cannot search the web or use Code interpreter. Small background jobs (choosing which manual chapters to load, spell-check, compaction and attachment memories) run on **Gemini 3.5 Flash-Lite**, a cheaper model on the same key. See [Token usage](/joe/token-usage#a-second-request-per-send-the-context-director).

If Google says your account or project has **no allowance** for the selected model, waiting or shortening the message will not create one. Check that key's project, **Billing Tier**, and model quota in Google AI Studio, then retry after the project has access. Google documents [model limits by tier](https://ai.google.dev/gemini-api/docs/rate-limits) and [billing status and upgrades](https://ai.google.dev/gemini-api/docs/billing). Joe returns this refusal immediately instead of waiting through retries. Antigravity’s Google login uses its own plan and limits; it does not give a Gemini API key paid project quota.

### Set up Claude or Grok with an API key

1. Open **Settings → APIs** and click the button beside **Anthropic API Key** or **xAI API Key**.
2. Paste your key. The empty field shows how the provider's keys start (`sk-ant-` for Anthropic, `xai-` for xAI), and the link under it opens the page where you create one ([platform.claude.com/settings/keys](https://platform.claude.com/settings/keys) or [console.x.ai](https://console.x.ai)).
3. Press **Test**. You see **Testing…**, then **Works** or **Key rejected**. The check lists your account's models; it does not send a prompt or cost anything.
4. Press **Save**, then pick the model in Joe's brain menu.

Some Anthropic answers have their own plain message:

* **Key rejected: Anthropic needs a key made inside a workspace** — this key was created outside any Anthropic workspace. Create a new key inside a workspace and paste that one.
* **The key works, but the account has no credit** — add credit to your Anthropic account, then try again.

**Test never saves.** Pressing **Test** checks the key you typed without storing it, for xAI too (FlowJoe checks xAI keys through the desktop app). Only **Save** changes your saved key, so a mistyped key never replaces one that works. xAI brains need the FlowJoe desktop app: in a plain web browser, Grok shows as "Desktop app only" in both brain lists and can't be picked, and **Test** in the xAI window says the same.

Like Gemini, these brains cannot search the web or use Code interpreter; the two switches are greyed out with a note that names the provider. Every one of these brains reads attached documents such as PDFs, Grok 4.7 included. If you send a message with an API-key brain whose key is missing, Joe tells you which key to add in **Settings → APIs** instead of sending it.

### What CLI brains need first

FlowJoe does not install a CLI brain for you. Install its tool and finish sign-in in your own terminal. The brain’s choice stays dimmed when FlowJoe cannot detect a usable installation or account:

| Brain | Needs this installed | Sign in by running |
|---|---|---|
| Fable 5.1 / Opus 5.5 / Opus 5 / Sonnet 5.5 / Sonnet 5 / Haiku | the `claude` CLI | `claude` |
| Grok | the `grok` CLI | `grok` |
| Antigravity | the `agy` CLI | `agy` |
| Codex (6.1 Sol, 6 Sol, 6 Luna, 5.6 Sol / Terra / Luna, 6 Astra) | the `codex` CLI | `codex login` (your ChatGPT account) |

**Codex** lets Joe run on your ChatGPT plan instead of an OpenAI API key. It offers the same OpenAI models as the API-key menu: GPT-6.1 Sol, GPT-6 Sol, GPT-6 Luna, GPT-5.6 Sol, Terra and Luna, and GPT-6 Astra. Quick helper tasks use GPT-5.6 Luna. Before Joe can use Codex for the first time, run `codex` once in a terminal so it saves its list of models on your computer; until then Joe tells you to do that. Which of these models your ChatGPT plan includes is up to OpenAI: if Codex doesn't offer the one you picked, Joe says so and you can pick another.

**Gemini CLI** is no longer one of Joe's brains: Google no longer lets individuals use that tool with a personal Google sign-in. Signed in to Google? Pick **Antigravity**, which uses the same Google account. Have a Gemini API key? Pick **Gemini 3.8 Flash** or **Gemini 4 Argon**. If Gemini CLI was Joe's brain, FlowJoe switched it to **Antigravity (3.8)** for you; if Antigravity isn't installed and signed in, Joe moves on to the first brain that works.

Antigravity offers **4 Argon** and **3.8 Flash**, both at Medium thinking. Quick helper tasks use 3.8 Flash Low. An older saved 3.7 choice now uses 3.8. Model access depends on your Google plan and installed Antigravity version.

If a brain is greyed out, check the explanation in the picker. The tool may be missing, not signed in, or unsupported on your platform. These brains use the tool’s own account and billing; you do not paste an API key into FlowJoe for them.

### Which brains can work with your Flow?

| Connection | What Joe can do |
| --- | --- |
| **OpenAI API** | Read permitted content and propose Flow changes. Web search and hosted Code interpreter are available when enabled. |
| **Claude-family CLI** | Read permitted content, use Flow tools, inspect supported images, and propose changes. Replies appear as they arrive. |
| **Grok CLI** | Read permitted content, use Flow tools, inspect supported images, and propose changes. Replies arrive together when ready. |
| **Codex CLI** | Read permitted content, use Flow tools, inspect supported images, and propose changes. Replies arrive together when ready. |
| **Antigravity** | On a Mac: read permitted content, use Flow tools, and propose changes. On Windows and Linux it can only discuss the context supplied with the conversation, and it runs with your own Antigravity settings. It cannot inspect image inputs through this connection. Web search is not available with Antigravity yet. Owner only; replies arrive together when ready. |
| **Gemini API** | Chat, permitted Flow reads, and proposals through the existing approval cards. No hosted web search or Code interpreter. |
| **Anthropic API** | Chat, permitted Flow reads, and proposals through the existing approval cards. No hosted web search or Code interpreter. |
| **xAI API** | Chat, permitted Flow reads, and proposals through the existing approval cards. No hosted web search or Code interpreter. Reads attached documents such as PDFs. Desktop app only. |

For brains with Flow tools, **Off / Read / Propose** sets the limit on what they can access through FlowJoe. Choosing a stronger brain does not unlock private content. Whichever brain you choose, Joe’s own changes always come to you as a card to approve; Agent Bridge’s **Apply changes without asking** setting only affects outside assistants. Guest Joe has separate invitation-based approval rules. See [Permissions & privacy](/joe/permissions).

Claude, Grok, Codex and Antigravity (on a Mac) use the same supported [Flow actions](/joe/propose-approve#what-you-can-ask-joe-to-change) as OpenAI. They connect to those actions through MCP, the connection format used by compatible AI tools. FlowJoe sets up this temporary connection for Joe automatically; you do **not** need to enable an outside assistant under Agent Bridge first.

The **Web search** switch also applies to CLI brains; their available search tools depend on the selected provider. Web search is not available with Antigravity yet, so the switch is greyed out while Antigravity is Joe's brain. FlowJoe’s hosted **Code interpreter** is an OpenAI feature, separate from running commands in a terminal. On launch, Web search starts on and Code interpreter starts off.

Choosing Codex as Joe's brain is separate from connecting those tools as outside assistants through [Agent Bridge](/joe/agent-bridge); you don't need one for the other.

### A CLI brain, Agent Bridge, or Forge?

These three features fit together without being the same thing:

- **BYOB** chooses who answers as Joe inside FlowJoe.
- **Agent Bridge** lets an outside assistant work with the active Flow, using its own connection and approval controls.
- **Forge** is FlowJoe’s [integrated terminal](/gallery/terminal), where you run commands or an interactive assistant yourself.

Joe’s chat history belongs to FlowJoe. Choosing a CLI brain does not resume a terminal conversation you already have open in Forge. **Stop** cancels the current CLI request; it does not undo changes already applied. Asking Joe to undo his last change works across the whole conversation on every brain that uses Flow tools (OpenAI, Gemini, and CLI brains such as Claude, Grok, Codex and, on a Mac, Antigravity). If a turn fails, FlowJoe shows the actual error or explains that the conversation is too large for that brain.

FlowJoe’s access settings control its Flow tools. They are not a general restriction on everything an owner’s installed command-line tool can do on the computer; that tool has its own permissions and configuration.

### What happens with no key and no CLI brain

Chat and AI writing need a supported brain. Image generation separately needs an **OpenAI API key**, even when your chat uses Gemini or a command-line brain. Free local transcription does not need an AI key. **Everything else works normally without any key** — your tree, galleries, notes, documents, workspaces, and import/export are entirely local and never need an AI provider.

## Your keys in Settings → APIs

**Settings → APIs** lists your keys in two groups (drag a row by its handle to reorder it within its group):

* **Your AI accounts:** **OpenAI API Key**, **Anthropic API Key**, **Gemini API Key** and **xAI API Key**.
* **Extra services:** **TypeSafe API Key**.

Under each name, a short line shows where that key stands:

* A green dot and **Key saved**, with the start and end of the key (for example `sk-proj…Q7f2`), so you can tell which key it is without revealing it.
* An empty dot and **No key yet**.
* A red dot and **Key rejected at last check**, when the last **Test** of the saved key failed. Saving a different key or removing it clears the red line.

Before you have saved any AI key, a sentence at the top explains what keys are for, and that supported terminal logins work without one.

## Viewing, copying and removing a key

1. Open **Settings → APIs** and click the button beside the key's name (for example **OpenAI API Key**).
2. By default, the key is hidden behind a password mask (`••••••••`).
3. Click the **Eye icon** (**Show key**) to reveal the plaintext key, so you can verify it or copy it.
4. To remove the key, click the **trash icon** (**Remove key**) beside the eye. FlowJoe asks first; **Cancel** is on the right and already selected, so pressing Enter keeps the key. The trash icon is dimmed while there is no saved key.

---

In the OpenAI key window, saves and removals finish in the order you request them. If you edit the key or reopen its window while an earlier change is finishing, that change will not close the newer window or erase your entry. Closing the window does not undo a storage write already underway. If storage reports a failure, the window stays open so you can try again.

## Making Joe faster: the optional TypeSafe key

Before Joe answers, he first works out what he needs to look at — whether you are asking him to change something, whether he needs the shape of your flow, which part of the manual is relevant. Its wait depends on the selected brain; a command-line helper also has to start its tool.

Add a **TypeSafe API key** and that decision runs on a model built purely for fast structured judgments, taking roughly a fifth of a second instead — on every message, whichever brain you are using.

The difference is largest on the CLI brains (Claude, Grok, Antigravity, Codex). When TypeSafe answers, Joe avoids starting a second copy of the command-line tool just to pick the manual chapters. If TypeSafe cannot answer or is unsure, the selected brain’s own helper tries within the time left; it never switches to another company’s model. See [the chapter picker and its waits](/joe/token-usage#a-second-request-per-send-the-context-director).

* It is **entirely optional.** Without a key, everything works exactly as it does today — including the flow map, which is then never trimmed (see below).
* If the key is missing, wrong, expired, or the service is unreachable, FlowJoe **quietly falls back** to the normal path. Nothing breaks — Joe is simply not faster, and the map is not trimmed.
* It is stored as securely as your OpenAI key, and it is a **separate** key: adding or removing one never affects the other.
* It is **desktop only.** The Test button explains when TypeSafe is unavailable rather than reporting a network error.

To set it up, get a key from [console.typesafe.ai](https://console.typesafe.ai), open **Settings → APIs**, click the button next to **TypeSafe API Key**, paste the key, press **Test**, then **Save**.

TypeSafe is a separate online service. When enabled, it receives relevant message text, node names (each with the name of the node it sits under) and summaries, file text, Joe’s replies, and — when Joe searches your pictures — small previews of them, for the routing, picture search and checks it performs. See [what TypeSafe checks and receives](/joe/token-usage#the-optional-typesafe-key). **Use TypeSafe** turns it off without deleting your key. **Double-check Joe’s work** turns the three trust checks on or off. Context selection and map ranking stay available while TypeSafe is on.

### It also trims a big flow map

With a TypeSafe key, the same model does a second job: when you send Joe your **whole** flow, it picks out the parts relevant to what you just asked.

This only applies when you have unticked **both** map options in the chat box — "Omit entire flow map" and "Limit map to my location". That is the case where Joe sees your entire tree on every message, which on a large flow is most of what you are sending him.

On a 274-node flow, one such question kept 41 nodes — the right branch and its parents — and left out the rest.

* **Nothing is hidden from Joe.** The map tells him it has been trimmed, how many of your nodes it is showing, and that anything not listed still exists. He can pull the full tree whenever he needs it, and is told to do that before ever saying something of yours does not exist.
* **Questions about the whole flow skip it.** "How many nodes do I have?", "what am I neglecting?", "do I have anything about X?" — these cannot be answered from a subset, so they get everything.
* **Any problem sends the whole map.** A slow answer, a garbled one, an answer that only covers some of your nodes, or a flow you edited while it was thinking — all of them fall back to the full tree. It never quietly sends Joe less.
* **Small flows are left alone** (under 60 nodes), and so are flows you have already narrowed with "Limit map to my location" — that is your choice of branch, not something to second-guess.

## Checking that a key works

The key panels have a **Test** button. Press it and FlowJoe makes one tiny real request to that provider and tells you immediately whether the key was accepted. Worth doing whenever you paste a new key — otherwise a mistyped or expired one looks fine until the next time you actually ask Joe something.

In the OpenAI key window, editing or removing the key, or closing the window, ends a pending test. Its old result cannot validate a new entry. Press **Test** again after changing the key; only **Save** stores it.

The same OpenAI Test can also collect announced shutdown dates for seven older image and online-transcription models. With Flow tools at **Read** or **Propose**, ask Joe which of those models have an announced retirement. The details are dated observations from the last completed manual Test, kept for this app session; they may come from an earlier key. Account access and future availability need separate checks. Missing retirement details leave Joe without that information and do not reject an otherwise accepted key. Test refreshes the observation, and removing the key clears it. Earlier replies keep their normal conversation history. Ordinary chat sends do not make another model-list request.


### CLI brains in shared conversations

A guest's Joe can use shared Flow tools and web tools, but cannot use the CLI to read your computer's unrelated files, run commands, or reach your other installed integrations. FlowJoe checks the installed CLI version before sending the guest's request. An unsupported version or a brain unavailable to guests stops that request; FlowJoe does not silently choose another provider. For the selectable CLI brains, supported guest release families are Claude 2.1.302 or later within 2.1, Grok 1.0.52 or later within 1.0, Codex 0.162.1 or later within 0.162 and 0.163.0 or later within 0.163. When a tool updates to a newer family, guests see a message that Joe can't use that brain in the shared conversation right now, until FlowJoe checks the new version; your own use is unaffected. Antigravity is not available to guests.

Grok uses a temporary connection for each Joe request. Guests can ask Joe to read shared content and propose changes for approval without approving a folder in Grok first. Their requests do not load your Grok, Claude Code, Cursor or Codex integrations, hooks, skills or instructions, or skills you keep in your home folder's `.agents` folder.

When you use Grok yourself, Joe uses your Grok sign-in and the models you set up, but none of your other Grok settings, tools or integrations. Like Claude, Joe on Grok can use only FlowJoe's Flow tools and, when Web search is on, web search. It cannot run commands, read or change files on your computer, or use your other connected tools. Joe uses the Flow access you selected for that request; choosing chat-only keeps Flow tools off even if you have also connected Grok through Agent Bridge. FlowJoe does not add temporary folders to Grok's saved trusted folders.

Codex works the same way, for you and for guests. Joe uses your sign-in, but none of that tool's other settings: not its instructions files (such as Codex's `AGENTS.md`), skills, plugins, extensions, hooks, memories or other connected tools, and not skills kept in your home folder's `.agents` folder. Joe can use only FlowJoe's Flow tools at the access you chose and, when Web search is on, web search. He cannot run commands or read or change files on your computer. If Codex refreshes your ChatGPT sign-in during a request, FlowJoe saves the refreshed sign-in back once the request ends, so you stay signed in.

When you use Antigravity on a Mac, Joe uses your Antigravity sign-in, but none of your other Antigravity settings, tools, plugins or integrations, including a FlowJoe connection you added through Agent Bridge. As on Claude and Grok, Joe can use only FlowJoe's Flow tools; Web search is not available with Antigravity yet. He cannot run commands or read or change files on your computer. Joe uses the Flow access you selected for that request, and choosing chat-only keeps Flow tools off. The picker checks your Antigravity sign-in with Google before showing Antigravity as ready.

On Windows and Linux, if you have connected Antigravity to FlowJoe under Agent Bridge, Joe will not use Antigravity as his brain: that connection would let him reach your Flow outside the access you chose for the chat. Disconnect Antigravity under **Settings → Joe AI → Agent Bridge (MCP)**, or pick another brain.
