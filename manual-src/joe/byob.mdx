**Bring Your Own Brain (BYOB)** lets you choose the intelligence behind Joe. Use your own provider API key, or connect a supported command-line assistant you already use. Your workspace lives locally; the context needed for an AI request goes to the chosen provider.

A command-line tool, or **CLI**, is an app you run by typing commands in a terminal. FlowJoe can use some of these tools behind the scenes, so you keep talking to Joe in the familiar chat panel.

---

## Why BYOB?

* **Your account, your usage:** API brains use your provider key and its usage charges. CLI brains use that tool’s account, plan, and limits. FlowJoe adds no markup to either connection. How much context you send affects usage; see [Token usage with Joe](/joe/token-usage).
* **Model Choice:** You choose exactly which model drives Joe—whether you want the speed of a lighter model or the reasoning of a frontier model.
* **Privacy & Control:** Owner requests go from your desktop to the selected provider or installed tool, rather than through a FlowJoe AI service. Shared guests use the owner’s authorized connection; they do not receive its credentials.

---

## 🔒 API Key Storage & Fallbacks

FlowJoe uses a multi-tier storage design for your keys to balance security and convenience:

* **Desktop storage:** Supported keys are encrypted using your operating system’s secure-storage service when available and saved in FlowJoe’s app data. A standalone browser, or unavailable secure storage, uses local browser storage with weaker protection.
* **Export choice:** Keys are excluded from portable exports by default. You can explicitly include an OpenAI key, so review that checkbox before sharing a package.

---

## Viewing & Copying Your Key

For easy verification, you can inspect or copy your stored API key:
1. Open **Settings → APIs → API Settings**.
2. By default, the key is hidden behind a password mask (`••••••••`).
3. Click the **Eye icon** on the input field to reveal the plaintext key, allowing you to quickly verify or copy it to your clipboard.

## Configuring Your AI Brain

To adjust your model config:
1. For an API brain, add its key in **Settings → APIs**. For a CLI brain, install and sign into its tool first, as described below.
2. Click the model settings button inside the Joe panel — or the brain name in the status bar — to pick the brain behind Joe:
   - **OpenAI models (API key):** **Sol 6.1**, **Luna 6** (the default), **Sol 6**, and **Astra 6**, plus **Luna**, **Terra**, and **Sol** from the GPT-5.6 family.
   - **Gemini API:** **Gemini 3.8 Flash** uses a separate Google Gemini API key. See setup below.
   - **CLI brains (no API key):** route Joe through an agent CLI you have already installed and signed into on your own machine — **Fable 5.1**, **Opus 5.5**, **Opus 5**, **Sonnet 5.5**, **Sonnet 5**, **Haiku**, **Grok**, **Antigravity (4 Argon)**, or **Antigravity (3.8)**. CLI installation and sign-in belong to the owner’s desktop. Authorized browser guests use a supported, isolated version of that selected owner CLI through Joe; they do not install it or receive its credentials. Antigravity is currently available only to the owner.
   - **Temperature and response length are managed automatically per model** — there is no manual temperature dial, and GPT-5.6 / GPT-6 models run at their fixed default temperature.

### Where to get an OpenAI key

Create one at [platform.openai.com/api-keys](https://platform.openai.com/api-keys), then paste it into **Settings → APIs → API Settings**. Keys start with `sk-`. You pay OpenAI directly for what you use; FlowJoe never takes a cut and never sees the key.

### Set up Gemini chat

Open **Settings → APIs → Gemini API Key**, paste a key from Google AI Studio, choose **Test**, then **Save**. Select **Gemini 3.8 Flash** in Joe’s brain picker. It supports chat and writing assistance. This connection can read permitted Flow content and propose Flow, memory and task changes through the existing approval cards. It cannot search the web or use Code interpreter.

### What CLI brains need first

FlowJoe does not install a CLI brain for you. Install its tool and finish sign-in in your own terminal. The brain’s choice stays dimmed when FlowJoe cannot detect a usable installation or account:

| Brain | Needs this installed | Sign in by running |
|---|---|---|
| Fable 5.1 / Opus 5.5 / Opus 5 / Sonnet 5.5 / Sonnet 5 / Haiku | the `claude` CLI | `claude` |
| Grok | the `grok` CLI | `grok` |
| Antigravity | the `agy` CLI | `agy` |

Antigravity offers **4 Argon** and **3.8 Flash**, both at Medium thinking. Quick helper tasks use 3.8 Flash Low. An older saved 3.7 choice now uses 3.8. Model access depends on your Google plan and installed Antigravity version.

If a brain is greyed out, check the explanation in the picker. The tool may be missing, not signed in, or unsupported on your platform. These brains use the tool’s own account and billing; you do not paste an API key into FlowJoe for them.

### Which brains can work with your Flow?

| Connection | What Joe can do |
| --- | --- |
| **OpenAI API** | Read permitted content and propose Flow changes. Web search and hosted Code interpreter are available when enabled. |
| **Claude-family CLI** | Read permitted content, use Flow tools, inspect supported images, and propose changes. Replies appear as they arrive. |
| **Grok CLI** | Read permitted content, use Flow tools, inspect supported images, and propose changes. Replies arrive together when ready. |
| **Antigravity** | Discuss the context supplied with the conversation. It cannot fetch more Flow content on demand, propose Flow changes, or inspect image inputs through this connection. Owner only; replies arrive together when ready. |
| **Gemini API** | Chat, permitted Flow reads, and proposals through the existing approval cards. No hosted web search or Code interpreter. |

For brains with Flow tools, **Off / Read / Propose** sets the limit on what they can access through FlowJoe. Choosing a stronger brain does not unlock private content. The owner’s tool-capable CLI brains also follow Agent Bridge’s session **Auto-apply agent edits** setting: leave it off to review each change; when it is on, ordinary changes can apply immediately and protected changes still wait for review. Guest Joe has separate invitation-based approval rules. See [Permissions & privacy](/joe/permissions).

Claude and Grok use the same supported [Flow actions](/joe/propose-approve#what-you-can-ask-joe-to-change) as OpenAI. They connect to those actions through MCP, the connection format used by compatible AI tools. FlowJoe sets up this temporary connection for Joe automatically; you do **not** need to enable an outside assistant under Agent Bridge first.

The **Web search** switch also applies to CLI brains; their available search tools depend on the selected provider. FlowJoe’s hosted **Code interpreter** is an OpenAI feature, separate from running commands in a terminal. On launch, Web search starts on and Code interpreter starts off.

Codex and standalone Gemini CLI are not choices in the current Joe brain picker. A compatible outside assistant can still connect through [Agent Bridge](/joe/agent-bridge); that is a separate way to work with your Flow.

### A CLI brain, Agent Bridge, or Forge?

These three features fit together without being the same thing:

- **BYOB** chooses who answers as Joe inside FlowJoe.
- **Agent Bridge** lets an outside assistant work with the active Flow, using its own connection and approval controls.
- **Forge** is FlowJoe’s [integrated terminal](/gallery/terminal), where you run commands or an interactive assistant yourself.

Joe’s chat history belongs to FlowJoe. Choosing a CLI brain does not resume a terminal conversation you already have open in Forge. **Stop** cancels the current CLI request; it does not undo changes already applied. If a turn fails, FlowJoe shows the actual error or explains that the conversation is too large for that brain.

FlowJoe’s access settings control its Flow tools. They are not a general restriction on everything an owner’s installed command-line tool can do on the computer; that tool has its own permissions and configuration.

### What happens with no key and no CLI brain

Chat and AI writing need a supported brain. Image generation separately needs an **OpenAI API key**, even when your chat uses Gemini or a command-line brain. Free local transcription does not need an AI key. **Everything else works normally without any key** — your tree, galleries, notes, documents, workspaces, and import/export are entirely local and never need an AI provider.

## Making Joe faster: the optional TypeSafe key

Before Joe answers, he first works out what he needs to look at — whether you are asking him to change something, whether he needs the shape of your flow, which part of the manual is relevant. That step normally takes about a second.

Add a **TypeSafe API key** and that decision runs on a model built purely for fast structured judgments, taking roughly a fifth of a second instead — on every message, whichever brain you are using.

The difference is largest on the CLI brains (Claude, Grok, Antigravity). Those used to start up a second copy of the command-line tool just to ask that one question, and wait up to fifteen seconds for it. That no longer happens.

* It is **entirely optional.** Without a key, everything works exactly as it does today — including the flow map, which is then never trimmed (see below).
* If the key is missing, wrong, expired, or the service is unreachable, FlowJoe **quietly falls back** to the normal path. Nothing breaks — Joe is simply not faster, and the map is not trimmed.
* It is stored as securely as your OpenAI key, and it is a **separate** key: adding or removing one never affects the other.
* It is **desktop only.** The Test button explains when TypeSafe is unavailable rather than reporting a network error.

To set it up, get a key from [console.typesafe.ai](https://console.typesafe.ai), open **Settings → APIs**, click the button next to **TypeSafe API Key**, paste the key, press **Test**, then **Save**.

TypeSafe is a separate online service. When enabled, it receives relevant message text, node names (each with the name of the node it sits under) and summaries, file text, Joe’s replies, and — when Joe searches your pictures — small previews of them, for the routing, picture search and checks it performs. See [what TypeSafe checks and receives](/joe/token-usage#the-optional-typesafe-key). **Use TypeSafe** turns it off without deleting your key. **Double-check Joe’s work** turns the three trust checks on or off. Context selection and map ranking stay available while TypeSafe is on.

### It also trims a big flow map

With a TypeSafe key, the same model does a second job: when you send Joe your **whole** flow, it picks out the parts relevant to what you just asked.

This only applies when you have unticked **both** map options in the chat box — "Omit entire flow map" and "Limit map to my location". That is the case where Joe sees your entire tree on every message, which on a large flow is most of what you are sending him.

On a 274-node flow, one such question kept 41 nodes — the right branch and its parents — and left out the rest.

* **Nothing is hidden from Joe.** The map tells him it has been trimmed, how many of your nodes it is showing, and that anything not listed still exists. He can pull the full tree whenever he needs it, and is told to do that before ever saying something of yours does not exist.
* **Questions about the whole flow skip it.** "How many nodes do I have?", "what am I neglecting?", "do I have anything about X?" — these cannot be answered from a subset, so they get everything.
* **Any problem sends the whole map.** A slow answer, a garbled one, an answer that only covers some of your nodes, or a flow you edited while it was thinking — all of them fall back to the full tree. It never quietly sends Joe less.
* **Small flows are left alone** (under 60 nodes), and so are flows you have already narrowed with "Limit map to my location" — that is your choice of branch, not something to second-guess.

## Checking that a key works

The key panels have a **Test** button. Press it and FlowJoe makes one tiny real request to that provider and tells you immediately whether the key was accepted. Worth doing whenever you paste a new key — otherwise a mistyped or expired one looks fine until the next time you actually ask Joe something.


### CLI brains in shared conversations

A guest's Joe can use shared Flow tools and web tools, but cannot use the CLI to read your computer's unrelated files, run commands, or reach your other installed integrations. FlowJoe checks the installed CLI version before sending the guest's request. An unsupported version or a brain unavailable to guests stops that request; FlowJoe does not silently choose another provider. For the selectable CLI brains, supported guest release families are Claude 2.1.302 or later within 2.1, and Grok 1.0.52 or later within 1.0. Antigravity is not available to guests.
