The **Agent Bridge** connects your active Flow to compatible AI assistants and developer tools on your computer. A coding assistant can work with your plan, references, and notes—not just the files in a code folder. MCP is the connection format these tools use.

## Connect a tool

1. Open **Settings → Joe AI → Agent Bridge (MCP)** in the desktop app.
2. Turn the bridge on.
3. Find your assistant under **Assistants on this machine** and turn on **Connect**. Follow any confirmation shown.
4. If FlowJoe offers **Copy setup command**, copy it and run it in that assistant’s terminal instead.

Claude Code, Codex, Gemini, Grok and Antigravity connect automatically; for Kimi, use **Copy setup command** and run it once. For supported assistants, Connect adds FlowJoe to that assistant’s settings across its projects. Other settings are preserved. Turn off Connect to remove FlowJoe’s connection.

For another compatible MCP tool, copy the connection details shown in the card into that tool’s settings. Keep the access token private. If you rotate it, update tools using the old token.

The bridge starts again on launch if you left it enabled. Turn it off here to stop access.

To use ordinary terminal commands or scripts, install the [FlowJoe CLI](/cli/getting-started).
Its dedicated manual section covers setup, commands, scripting and troubleshooting. The CLI's
`--autoapprove` flag skips approval cards for that command, including deletion approvals; it does
not change this card's saved settings or other agents' approvals.

## Choose how changes are approved

**Read-only access for external agents** allows inspection but blocks Flow change requests.

Otherwise, changes wait for approval by default. An **Agent request** card lets you approve or reject them even when Joe chat is closed.

You can enable **Auto-apply agent edits** for the current session. Deletions, repository file edits, scheduled-task and saved-memory changes, and revealing hidden-from-Joe nodes still require review. The **Auto-apply** setting turns off when the bridge stops or FlowJoe relaunches. It only affects outside assistants: Joe’s own changes in Joe chat always ask you first, whichever brain you choose. Leave it off if you want to review each change. Guest Joe uses the invitation’s separate approval rules.

## How MCP relates to Joe’s actions

MCP is how a compatible assistant discovers FlowJoe’s tools and asks to use them. The tools include reading and search, preparing media, and proposing changes. A change request can combine several supported actions—such as creating nodes, moving cards, and building a stack—into one review.

Connected assistants use the same [supported Flow changes](/joe/propose-approve#what-you-can-ask-joe-to-change) as Joe’s tool-capable brains. They also follow FlowJoe’s privacy and target restrictions. Their own file access, terminal commands, and other integrations are governed by the assistant’s separate settings.

Choosing a CLI brain for Joe is the other direction: the installed tool answers **inside Joe chat**. FlowJoe automatically supplies that supported brain with a temporary connection; you do not need to connect it here first. The **Connect** controls and the **Auto-apply** setting are for assistants working **outside** Joe chat; Joe’s own changes always ask you first, as explained above.

## What connected tools can do

Compatible tools can inspect and search permitted Flow content, read supported documents and media, supply files, generate images with your configured OpenAI connection, and propose changes. Joe himself, on every brain that uses Flow tools (OpenAI, Gemini, and CLI brains such as Claude, Grok, Codex and Gemini CLI), can do a few things that assistants connected from outside cannot: hand you a restore, export, import or outside-changes review, find pictures by what they show, read terminal lines you share, or keep reading a browser page in parts (a page you explicitly ask about still reaches every assistant as context). Each of these still follows Joe’s permission level: cards need Propose and reads need Read. See [Only in Joe’s chat](/cli/action-reference#only-in-joes-chat). On a Mac this includes Antigravity; on Windows and Linux, Antigravity can't use Flow tools yet.

File requests appear in FlowJoe even when Joe chat is closed. Files uploaded by a tool belong to that connection and are cleared when it disconnects.

Each connection has its own recent-change history, supplied files, and approval results. It does not inherit Joe’s chat attachments or conversation history. Its undo action works only if the Flow has not changed since that connection’s last applied change.

Run the connected assistant in [Forge](/gallery/terminal) or another terminal. This desktop connection is separate from [Joe’s choice of brain](/joe/byob) and from [browser sharing](/workspaces/sharing-and-presenting).
