title: "Agent Bridge (MCP)"
description: "Let a local coding assistant work with your Flow while you stay in control."
---

The **Agent Bridge** connects your active Flow to compatible AI assistants and developer tools on your computer. A coding assistant can work with your plan, references, and notes—not just the files in a code folder. MCP is the connection format these tools use.

## Connect a tool

1. Open **Settings → Joe AI → Agent Bridge (MCP)** in the desktop app.
2. Turn the bridge on.
3. Find your assistant under **Assistants on this machine** and turn on **Connect**. Follow any confirmation shown.
4. If FlowJoe offers **Copy setup command**, copy it and run it in that assistant’s terminal instead.

For supported assistants, Connect adds FlowJoe to that assistant’s settings across its projects. Other settings are preserved. Turn off Connect to remove FlowJoe’s connection.

For another compatible MCP tool, copy the connection details shown in the card into that tool’s settings. Keep the access token private. If you rotate it, update tools using the old token.

The bridge starts again on launch if you left it enabled. Turn it off here to stop access.

## Choose how changes are approved

**Read-only access for external agents** allows inspection but blocks Flow change requests.

Otherwise, changes wait for approval by default. An **Agent request** card lets you approve or reject them even when Joe chat is closed.

You can enable **Auto-apply agent edits** for the current session. Deletions, scheduled-task and saved-memory changes, and revealing hidden-from-Joe nodes still require review. The **Auto-apply** setting turns off when the bridge stops or FlowJoe relaunches.

## What connected tools can do

Compatible tools can inspect and search permitted Flow content, read supported documents and media, supply files, generate images with your configured OpenAI connection, and propose changes.

File requests appear in FlowJoe even when Joe chat is closed. Files uploaded by a tool belong to that connection and are cleared when it disconnects.

Each connection has its own recent-change history and approval results. Its undo action works only if the Flow has not changed since that connection’s last applied change.

Run the connected assistant in [Forge](/gallery/terminal) or another terminal. This desktop connection is separate from [Joe’s choice of brain](/joe/byob) and from [browser sharing](/workspaces/sharing-and-presenting).
