FlowJoe uses **Tags** and **Virtual Galleries** to provide dynamic, cross-cutting discovery views across your entire project hierarchy.

---

## Tag Registry

Manage your tag vocabulary in the Flow-level registry:
- **Registry Location:** Stored at the root of the Flow file.
- **Customization:** Add, rename, recolor (assign category colors), merge, or delete tags.
- **Usage Counts:** The registry displays how many slots are tagged with each label.

---

## Assigning Tags to Slots

- **Tag Editor:** Click the tag badge on any gallery slot to open the tag picker.
- **Assigning and reusing tags:** Use the **Tag Manager** to assign tags. The slot menu also lets you copy tags and paste or merge them onto other cards.
- **Stack Tagging:** Stacks can be tagged as a single unit, or individual items within a stack can hold separate tags.

---

## Virtual Galleries

A **Virtual Gallery** is a dynamically generated gallery view. 
Use **Query by tags** (`Q`) to choose tags, or open gallery search and turn on **All nodes** to gather matching references into one view. In gallery search, **Include tags**, **Include file names**, and **Include document text** expand what is searched. Without **All nodes**, search filters the current gallery. You do not need a special search expression.

### The Rules of Virtual Galleries

To protect your folder hierarchy and avoid accidental data mutations, Virtual Galleries are **structurally read-only**:

| Action | Allowed in Virtual Gallery? | Notes |
| :--- | :--- | :--- |
| **Preview Media** | Yes | Open PDFs, play audio, maximize images |
| **Edit Slot Notes** | Yes | Edits save directly to the origin slot |
| **Origin Jump-Back** | Yes | Click the origin card badge to jump to the real node in the tree |
| **Drag & Drop Reorder** | **No** | Order is determined by search relevance |
| **Merge Stacks / Delete** | **No** | Must perform structural edits on the origin node |

<Note>
A virtual gallery is a view of existing content, not a new destination. Jump to the origin node before reorganizing its cards, and check Joe’s **Flow / Node / Slot** target before requesting changes. See [Choosing Joe’s target](/joe/opening-joe).
</Note>
