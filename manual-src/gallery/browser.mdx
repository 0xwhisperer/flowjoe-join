The desktop app includes an **In-App Browser**. Browser guests open web links in their own browser rather than using the owner’s browser panel. Because research shouldn't force you to toggle between your workspace and external browsers, FlowJoe embeds web browsing directly into the visual shell, allowing you to clip content, capture screenshots, and save bookmarks in one click.

---

## 🌐 The Browser Interface

The in-app browser is powered by a secure, sandboxed Electron runtime and features standard browser controls:
* **Tab Management:** Open multiple tabs, reorder them, pin tabs to save space, and organize tabs into color-coded **Tab Groups**.
* **The Start Page (`flowjoe://start`):** Your launchpad containing a Google/web search bar, lists of recent tabs, history logs, and your bookmarks.
* **Persistent Session Restore:** If you close FlowJoe, reopening the app automatically restores all your open tabs, their tab groups, and their complete back/forward navigation stacks.

---

## ✂️ One-Click Web Clipping (Send-to-Gallery)

The main superpower of the embedded browser is its tight integration with the gallery:
* **Send to Gallery:** From any active web page, click the **Send to Gallery** button (or right-click and choose **Send Tab to Gallery**).
* **Metadata Extraction:** FlowJoe automatically extracts the page title, description, favicon, and canonical URL.
* **Full-Page screenshots:** Electron opens a background renderer to take a clean screenshot of the web page, saving it as a high-fidelity visual card directly in your active node's gallery.
* **Branded Fallbacks:** If you save empty placeholders or documentation domains (e.g. `example.com`), FlowJoe automatically renders them as branded cards (using the signature coffee-mug logo), preventing clutter.

---

## 🔖 Bookmarks & Favorites

Organize your web references with a powerful bookmarks system:
- **Quick Bookmark:** Click the star icon in the address bar to add a page to your favorites.
- **Bookmark Folders:** Save pages into custom folders. You can right-click a folder to open all links at once, turn a folder into a tab group, or send a folder's URLs directly to your outlines.
- **Bookmark All Tabs:** Right-click the tab strip to bookmark all open tabs into a new folder instantly—perfect for packing up a research session.
- **Import/Export:** Sync bookmarks, tab groups, and history between devices. You can choose to **merge** new imports or **replace** existing local databases.

---

## 🕰️ History & Retention Policies

FlowJoe records a chronological log of all your visits, saved locally in IndexedDB:
- **Retention Controls:** Configure history cleanup intervals in Settings (keep visits forever, or prune after 30, 90, or 365 days).
- **Smart Pruning:** When old history visits are pruned, FlowJoe **preserves all metadata for bookmarked pages**, ensuring your saved sites never lose their titles or descriptions.
- **History to Folder:** Turn any history time-bucket (e.g., "Yesterday's research") into a permanent folder or send it straight to an outline node.

---

## 🔒 Security & Privacy Gating

FlowJoe treats web security as a priority:
- **Sandbox Mode:** Web views run with `nodeIntegration: false`, `contextIsolation: true`, and `sandbox: true` to prevent malicious scripts from accessing local files.
- **Website permissions:** Websites in this panel cannot use the camera, microphone, or location. Open a site in your regular browser if it needs those permissions. Downloads follow the browser’s download settings, including whether to ask for a save location.
- **Clear Browsing Data:** In **Settings → Browser**, choose **Website Data**, **FlowJoe Browser Data**, or **Both**. Website data covers cookies and temporary files for known sites. FlowJoe browser data includes bookmarks, history, tabs, tab groups, and saved sessions; clearing it resets the tabs to the home page. Export browser data first if you want to keep it.


## Asking Joe about the page

In the desktop app with Joe's Read access, explicitly ask Joe to read or summarize the current page. Explicit requests and refusals are recognized in all20 app languages. The page is shared for that request only; the page text is not saved into chat history. Unknown wording may need a clearer request.

Joe can read the captured page in parts and receives its title, URL and capture time. Switching tabs, navigating or reloading cancels the old capture. The existing page extraction limit still applies, and Joe is told when the capture is incomplete. A model-generated tool request cannot grant permission on your behalf. Guest sessions and scheduled tasks cannot read the owner's open browser page.


The existing page context continues to work with each selectable Joe provider. Before sending it, FlowJoe checks that the page and your access still match the request. If either changed while Joe was preparing, that response is cancelled. In Joe’s chat, on every brain that uses Flow tools (OpenAI, Gemini, and CLI brains such as Claude, Grok, Codex and Gemini CLI), the page-reading tool can continue the same capture in parts. Antigravity can't use Flow tools yet; that's being fixed. External agents, including the FlowJoe CLI, cannot use that page-reading tool, because they have no way to receive your page approval; the page you explicitly ask about still reaches every provider as context.
