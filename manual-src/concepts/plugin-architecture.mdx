---
title: "About future plugins"
description: "What the planned plugin system means for people using FlowJoe today."
---

FlowJoe’s tree, references, and Joe already suit many kinds of work. A future plugin system is planned to add more specialized tools—for example, character fields for a story bible or experiment templates for a lab notebook.

The plugin installer, marketplace, and custom plugin panels are not currently available. Proposed plugin formats are design plans, not features you can turn on in Settings.

You can build a tailored workspace today using nodes, tags, summaries, spreadsheets, calendars, and recurring Joe tasks. For outside AI tools, the existing [Agent Bridge](/joe/agent-bridge) lets a connected agent read permitted content and request reviewed changes.

See [Ways to use FlowJoe](/concepts/ways-to-use-flowjoe) for practical starting points and [Plugins & specialized workflows](/concepts/plugins-verticals) for the direction of future plugins.
