FlowJoe’s mix of structure, references, and Joe works well for projects with a vocabulary of their own: characters and scenes, clients and evidence, experiments and datasets, episodes and takes.

You can shape those workspaces today using nodes, tags, summaries, spreadsheets, calendars, and saved Joe memories. See [Ways to use FlowJoe](/concepts/ways-to-use-flowjoe) for examples.

## What plugins would add

A future plugin system is planned to offer specialized fields, ready-made project templates, custom views, and domain-specific help from Joe. For example, a story plugin could add character fields and a story-bible template; a research plugin could organize experiment records.

The plugin installer, marketplace, and custom plugin panels are not currently available. These ideas describe future work rather than settings you can enable in today’s app.

## Useful tools already available

- [Repo nodes and Git](/tree/repositories) bring code, file editing, branches, and version control into a visual project.
- [Workbenches](/workbenches/spreadsheets) put editable sheets, documents, and calendars beside your references.
- [Joe](/joe/opening-joe) can help analyze material and propose changes you review.
- [Agent Bridge](/joe/agent-bridge) connects compatible local AI tools to permitted Flow content.

Start with the workspace you need now; no plugin is required.
