FlowJoe provides native visual indicators and safety features to help you categorize work, organize outlines, and secure sensitive information.

---

## Node Status

Every node in FlowJoe can display a status badge. This is useful for project tracking:
- **Status Options:** Choose **Not Started**, **In Progress**, **Completed**, or **Neutral**. Number keys 1–4 set these in that order when the tree has focus.
- **Bulk changes:** A parent status change updates editable nodes and skips frozen or password-locked branches. Unlocked siblings still change. The parent badge reflects all children, so a mix of changed and protected children can leave it **In Progress**.
- **Tree Filtering:** Use the tree filter controls to choose a status. The tree search box searches node names.
- **Undo:** When **Delete Undo (5s)** is enabled, Undo after a parent status change restores each child’s previous status, including mixed statuses inside nested groups. The restored values are saved.
- **Joe Awareness:** Joe is aware of node statuses and will use them to prioritize suggestions.

## Branch Theming & Inheritance

To help organize different zones of a large workspace (e.g. distinguishing personal logs from client tasks), FlowJoe supports custom branch themes:
- **Color Coding:** Right-click a node, select **Theme**, and choose a color profile.
- **Inheritance:** By default, children nodes inherit their parent's color theme. This lets you color-code an entire branch (and its gallery slots) in one click.
- **Theme Profiles:** Global styling themes (Dark, Light, Cozy, Sepia) are managed in Settings.
- **Joe:** You can ask Joe to set a node's Theme-menu look by its menu name, such as Clay Roast, or ask for a calming, earthy, light, or dark look. He is shown each look's colors and uses those, not the name alone. A name that is not on the list is refused.
- **Bulk theme clearing:** **Remove All**, resetting node themes to the global theme, and resetting preferences leave frozen or password-locked branches unchanged while clearing editable nodes’ overrides.
- **Clear or app theme:** Clearing that look lets the node inherit from its parent again. Asking for the app theme uses the app-wide look on that node and stops inheritance. A frozen or locked Private node refuses the change.

## The Four Node Protection States

<Frame caption="Choose the control for the job; visibility, editability and AI access are separate decisions.">
  <img src="/images/diagrams/node-protection.svg" alt="Four independent controls: Hidden affects browsing, Frozen blocks edits, Private requires owner password access and excludes content from guests, and Hidden from Joe seals contents from AI." />
</Frame>

FlowJoe supports four independent (orthogonal) node states that can be toggled via the **Set Visibility / Privacy…** context-menu flyout. These states inherit down the tree, meaning freezing or privatizing a parent applies to the entire subtree.

| State | Purpose | Visible? | Editable? | Secret? | Mechanism |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Hidden** | Declutter the tree sidebar | No (filtered out) | n/a until shown | No | `node.hidden` boolean toggle |
| **Private (password)** | Access control / privacy | **No** until unlocked | No until unlocked | **No** (Verifier-only; not encrypted at rest) | Durable `lockKey` verifier + temporary memory unlock session |
| **Frozen** | Prevent accidental edits | **Yes** (fully readable) | **No** (read-only) | No | `node.frozen` boolean toggle |
| **Hidden from Joe** | Seal content from AI assistant | **Yes** to the human | **Yes** to the human | No | `node.hiddenFromJoe` boolean toggle |

### 1. Hidden Nodes
Hiding a node filters it out of the tree view sidebar without deleting it. 
* To view or edit hidden nodes, toggle **Show Hidden Nodes** from the tree panel menu.
* Hidden nodes remain fully editable and unprotected once revealed.

### 2. Frozen (Read-Only) Nodes
Marking a node as Frozen (padlock icon) keeps its gallery content from being changed by accident. Flows saved earlier with a node "locked" now show that node as frozen, and it works the same way:
* **What is Allowed:** You can still reorder/move the node on the tree, copy/export content, and duplicate the branch (the duplicate is created as a new, fully editable, unfrozen sibling).
* **What is Blocked:** You cannot rename the node (unfreeze it first), edit slot notes or titles, crop/delete images, reorder or navigate stacks, attach new media, set statuses, or delete the node itself.
* **Unfreeze Toggle:** Clicking the padlock badge in the gallery header opens a confirmation modal before unfreezing.

### 3. Private (Password-Protected) Nodes
In a password window, **Tab** and **Shift+Tab** move through its current controls. **Enter** activates a focused button, including **Cancel** and the password reveal button. **Escape** or **Cancel** returns to where you opened it; focus stays put if you have moved to another window. Empty or mismatched entries identify the affected field and expose the error to assistive software.

When a recovery key is shown, **Copy key** leaves that window open. If automatic copying is unavailable or refused, select and copy the displayed key yourself. Choose **I saved this recovery key** only after saving it; **Cancel protection setup** remains available.

Private nodes require a password to view their contents in FlowJoe. After unlocking, use normal Joe context, attachments and approved actions; choose Hidden from Joe separately to withhold content from him. Their saved content and media are not encrypted at rest. For a protected portable backup, explicitly include the Private node and enable package password protection; see [Password-protected packages](/portability/export-import#password-protected-packages). Importing that backup preserves the node’s separate password lock.
* **Temporary Unlock:** Right-click and enter your password. This starts an in-memory session. Leaving the node, reloading the app, disconnecting the workspace, opening another Flow, starting a New Flow, importing over the current Flow, or restoring a version immediately re-locks it.
* **Workspace Folder privacy:** Workspace files show a redacted **Private node (not shared)** placeholder. When an older Flow is opened, FlowJoe preserves the private content in owner-only storage and verifies the redacted folder file before saving resumes. Copies made before migration cannot be recalled. If a retained backup still contains private text, FlowJoe replaces that text with a placeholder (your private notes stay on this computer) and removes any backup too damaged to check; see [Workspace Folders](/workspaces/folders).
* **Stays on this computer:** A private node's content stays on the computer where it lives. It does not follow you to your own second computer, even through the same Workspace folder; there it shows only as the placeholder.
* **Removal:** To share the node again, choose *Remove Password Protection* (this requires your password, permanently clears private status, and republishes the node).

### 4. Hidden from Joe Nodes
Marking a node as Hidden from Joe seals the entire node and its children from the AI assistant:
* **Human View:** The node remains fully visible and editable to you.
* **AI Block:** Joe cannot read the summary, gallery media, slot notes, or tags of the node.
* **Tool Exclusions:** Joe is barred from running mutations, auto-titling, spelling checks, or image generation tools on the node, and the snapshot API emits it as redacted.
