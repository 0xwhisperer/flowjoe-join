## Creating Nodes

You can build your tree quickly using keyboard shortcuts or mouse clicks:
- **New node (keyboard):** Press **`N`** or **`Ctrl+N`**. With a node selected, the new node is added as a **child**. With no node selected, it becomes a **root**. (On Mac, **`Cmd+N`** is New Flow, not add node.)
- **Context Menu:** Right-click any node and choose **New Node** or **New Child**.
- There is **no** Enter / Tab / Insert shortcut for creating siblings or children.

Once Add Node is open, use **Tab** or **Shift+Tab** to reach **Password protect** and its lock policies. The timeout field joins that keyboard cycle when shown; hidden fields and disabled actions are skipped.

Cancelling the password step returns to Add Node with your name and privacy choices intact. If another window replaces the password or recovery-key step, node creation is cancelled and the new window stays open.

## Renaming Nodes

- **Quick Rename:** Select a node and press **`F2`** or **`Enter`** (single selection, tree focus, not while typing in a text field), or double-click the node text to enter edit mode.
- **Save Name:** Press `Enter` or click outside the text box to save the new name.
- **Cancel Rename:** Press `Escape` to revert to the original name.

---

## Reordering & Dragging

You can reorder nodes dynamically:
- **Move without dragging:** Right-click a node, choose **Move Node…**, then choose the root, a parent, or a sibling destination. Keyboard users can open the node menu and operate the destination picker without a pointer.
- **Drag and Drop:** Click and hold a node to drag it. You can move it between siblings or nest it under a new parent.
- **Drop Indicators:** A horizontal bar shows where the node will land if dropped between others. Highlighting a node indicates it will become a child of that node.
- **Subtree Moving:** Dragging a parent node automatically moves all of its nested children, preserving the entire sub-hierarchy.

Move Node applies the same branch and destination protection rules as dragging. If a move is allowed, the Undo notification can restore the branch to its previous location.

---

## Duplicating & Deleting

- **Duplicate Subtree:** Right-click a node and select **Duplicate**. This creates an exact copy of the node, its entire nested child tree, and all associated gallery slots and summaries.
- **Delete:** Select a node and press `Delete` or `Cmd/Ctrl + Backspace`. Deleting a parent node requires confirmation if it contains children, safeguarding you from accidental data loss.

> [!TIP]
> **Subtree Exports:** You can also export a selected subtree as a standalone `.fj` file for sharing. See [Export & Import](/portability/export-import) to learn more.
