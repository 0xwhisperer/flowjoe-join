The left hemisphere of FlowJoe is the **Tree**. As your project grows, knowing how to navigate, filter, and edit the tree in bulk keeps you fast and organized.

---

## Basic Navigation

You can navigate the tree using either your mouse or standard keyboard shortcuts:
- **Arrow Keys:** Use `Up` and `Down` to move selection.
- **Left Arrow:** Collapse the selected node.
- **Right Arrow:** Expand the selected node.
- **Spacebar:** Toggle node expansion. **Enter** or **F2** renames a single selected node when you are not typing in a field.

---

## Search & Filter

At the top of the tree panel is a search bar. Typing into this bar filters the tree in real time:
- **Name search:** Matching node names stay visible together with their ancestors, so you can see where each result belongs.
- **Filters:** Use the tree filter controls for tags, status, visibility, privacy, and frozen state. These are separate from name search.
- **Preserved Collapse State:** When you clear the search or close the filter, the tree returns to its exact previous collapse state. You won't lose your place by quickly checking a keyword.

---

## Multi-Select Operations

For bulk organization, FlowJoe supports select operations:
- **Cmd/Ctrl + Click:** Select multiple non-adjacent nodes.
- **Shift + Click:** Select a range of adjacent nodes.

With multiple nodes selected, you can perform **bulk actions**:
- **Drag & Drop:** Move a group of nodes to a new parent.
- **Bulk Delete:** Delete multiple branches at once (with confirmation).
- **Status Change:** Mark multiple nodes as "In Progress" or "Done" simultaneously.
- **Theming:** Assign color highlights across multiple nodes.

---

## 📌 Pinned Node Context Menu

Right-clicking any node in the tree opens a context menu with essential operations:
* **Add & Sibling Tree Management:** Quickly create Child or Sibling nodes, or add a new Root branch.
* **Visibility & Status Toggles:** Set status to Not Started, In Progress, Completed, or Neutral, or change protection settings (Hidden, Frozen, Private, Hidden from Joe).
* **Attach Items & Clipboard Media:** File-picker shortcuts to attach media assets, or paste clipboard images/videos directly **To Start** or **To End** of the node's gallery without shifting your current selection.
* **Subtree Actions:** Easily duplicate nodes, copy raw Node JSON, or export selected subtrees.

### Floating & Draggable Toolbar
The context menu is designed as a **Floating, Draggable Surface**. 
- Click the **Pin** icon in the corner to lock the menu open on the screen, converting it into a persistent floating panel.
- Drag the panel by its top header to keep a handy command center open while working.
- **Claims System:** Pinning a new floating menu (such as the Theme Manager or Tag Manager) automatically closes previously pinned menus to keep your workspace uncluttered.

> [!WARNING]
> **Nesting Limit:** While you can nest nodes as deeply as you need, we recommend keeping your hierarchy structured cleanly. Deeply nested, flat structures can sometimes make sidebar navigation less scannable. Use [Summaries](/tree/summaries) to aggregate deep child details!
