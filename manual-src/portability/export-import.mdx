FlowJoe ensures your data is completely portable. You can move individual branches or entire workspaces between devices, and protect sensitive exports with whole-package encryption.

---

## Export Formats

FlowJoe supports two primary export shapes:

### 1. Data-Only JSON (`.json`)
- **What it contains:** The complete tree structure, text notes, summaries, tag mappings, and slot metadata.
- **What it omits:** The actual media binary files (images, audio, PDFs are referenced by name but not bundled).
- **Best For:** Small backups, version-tracking text in Git, or sharing outlines.

### 2. Full-Package Media Bundle (`.fj`)
- **What it contains:** The tree and the media referenced by the Flow or branch you export, gathered from its active storage. Unused database files are not bundled.
- **Best For:** Archiving projects, backing up files, or moving your work to a different machine.

Linked local files remain references; their original files are not bundled. Copy those files separately and relink them on the destination computer.

## Transcript history

The export window’s **Include transcript history** option is enabled by default for JSON and full packages, including password-protected exports. It includes completed transcript text and retained edits, even if you have not saved a gallery copy. Turn it off to omit this history. Private-source transcripts and records marked **Keep on this computer only** are always excluded. A gallery copy is part of the gallery’s ordinary data and follows that data’s export rules.

Whole-Flow imports restore included history under the imported Flow’s local identity. Merge imports remap its source links to the imported nodes and slots. **Import Node(s)** includes history only for the selected imported branches. History can still be opened, copied, and saved when its original recording is missing; a JSON export does not carry the recording’s media file.

In Local mode the restored history lives in local app/browser data. In Workspace mode eligible history also goes into `.flowjoe/transcript-history.json`; that file is separate from the Workspace’s main Flow JSON. You can reopen, remove, or clear records from **Recent transcripts** in Joe’s Transcribe tab. Clearing history leaves original recordings and saved gallery copies in place.

## Password-Protected Packages

When exporting a full package or data-only JSON, you can secure your backup by checking **Protect this `.fj` with a password** in the export prompt:

The password protects the whole exported file, including its outline, included media, and filenames. FlowJoe asks for the password before opening it. A wrong password leaves the current Flow unchanged.

This protects the package, not your live Workspace Folder. Keep the password somewhere safe so you can open the backup later.

## Ingesting & Importing

When you import a `.json` or `.fj` file, FlowJoe prompts you for a merge strategy:
- **Overwrite:** Replaces the current Flow with the imported backup after protecting the outgoing Flow. The imported Flow receives a fresh local identity.
- **Merge at Root:** Appends the imported nodes as new roots side-by-side with your existing workspace.
- **Merge Under Selected:** Ingests the imported subtree as nested children under the currently selected node.

When a package has enough verified information to compare it with the connected Workspace,
FlowJoe explains whether using it would advance the Workspace or replace it with an older version.
It protects the current Flow and asks before updating it. A saved revision number alone does not
prove which version is newer: packages from another app session or computer, and older packages
without that proof, use the existing safe choices to keep the Workspace or open the package as a
new Flow. Restarting the app does not mean the package belongs to a different Flow; it means its
revision number cannot safely establish the relationship.

*Protected nodes inside an imported package retain their individual password locks even after the package itself is unlocked and imported.*

## Clipboard Transfer (Copy JSON)

- **Copy Node JSON:** Right-click a node and select **Copy Node JSON**. This puts the branch’s structure and metadata onto your clipboard. Media files are not bundled into the copied text. You can paste this code block directly into a text editor or share it with Joe.
- **Copy Slot JSON:** Right-click a gallery card to copy individual card styling, tags, and notes data.

## Shared transcript history

Shared guests read retained transcripts from the owner's Flow; their browser's pending edit recovery is not an independent export source. The owner’s export can include eligible retained transcript text with **Include transcript history**, subject to the privacy rules above. A guest's export/download availability still follows the permissions granted for that share. Clearing guest browser data does not delete owner-retained transcripts. See [Transcribe audio](/joe/transcription).

## Cancelling a browser export

Cancel releases the export controls even if the browser is still finishing a file operation.
FlowJoe removes a newly created empty file when it can safely do so. It preserves existing backups,
files changed elsewhere, and completed files. If the browser finishes saving after you press Cancel,
the completed file stays on disk; check that destination before starting another export.

## Conversations and sharing choices

Use **Include AI chat and image history** to carry eligible history with the exported work. Private-node and computer-only conversations are excluded, together with their chat-only backup pictures and image-history prompts. A picture independently saved in an ordinary gallery follows the gallery’s export rules. A branch export includes only eligible chat and image history belonging to that branch.

Full packages include the backup pictures that eligible current and older chats still use, even after you delete their separate Image History rows. Plain JSON keeps the references but does not carry picture bytes. Imported image history follows the imported Flow, nodes and slots instead of attaching itself to an older Flow with matching identifiers.

Whole-Flow exports can separately include **sharing setup** and **conversations guests had with Joe**. Review guest names and saved history before including them. Imported sharing choices are inactive until you review them in **Share** and send fresh invitations; old links do not open the imported Flow.

Version History and restore points stay with the app on the original computer. See [History & recovery](/workspaces/recovery) for the difference between portable conversation history and local restore points.
