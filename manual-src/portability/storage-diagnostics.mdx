## Check storage

Open **Settings → Data → Storage Stats** to see how much data FlowJoe keeps on this computer.

The local database holds your Local Flow, media, and growing records such as histories. Smaller browser storage mainly holds settings and recovery information. A connected Workspace Folder is a separate storage destination.

Use the inspection controls before deleting anything:

- **Inspect Orphaned Media** finds files no longer referenced by saved work.
- **Inspect Stale References** checks references whose files may be missing.
- **Inspect Orphaned Image Prompts** finds image-prompt records no longer attached to their images.
- **View Diagnostics Log**, on desktop, opens troubleshooting information.

Read the inspection results before choosing a cleanup. Export a backup first if you are unsure.

## Automatic saving and portable backups

FlowJoe saves normal edits automatically to the active storage. Check the bottom save indicator for pending or blocked saves.

**File → Export Flow**, the save indicator, and **Cmd/Ctrl+S** create a portable backup. Changes waiting to be exported are separate from whether the current storage save succeeded. See [History & recovery](/workspaces/recovery) if saving is blocked.

## Include preferences

Use **Settings → Data → Save Preferences With Exports** to include choices such as appearance, audio settings, and saved playlists in an export.

API keys are excluded by default. Only select **Include OpenAI API key in export** when you intend the recipient to receive that credential.
