This guide demonstrates how to manage multiple creative design iterations and catalog them using tags.

---

## Workflow Steps

### Step 1: Set up a Creative Branch
1. Create a node named `Creative Assets`.
2. Under it, add children nodes for `Logos`, `Mockups`, and `Copy Drafts`.

### Step 2: Combine Iterations into Stacks
1. Drag your first logo design (`logo_v1.png`) into the `Logos` gallery.
2. Drag `logo_v2.png` and drop it **directly on top** of the first logo card.
3. FlowJoe creates a **Stack**. Use the left/right arrow buttons to cycle through the versions.
4. Hover over the stack and drag thumbnails to promote a new version to the top active preview.

### Step 3: Define and Apply Tags
1. Select a slot, click the tag badge, and select **Edit Tags**.
2. Create tags named `Approved`, `In-Review`, and `Needs-Work` with corresponding visual colors.
3. Assign the `In-Review` tag to the stack.

### Step 4: Filter by Tag
1. Type `tag:In-Review` in the gallery search bar.
2. FlowJoe dynamically hides other assets.
3. Clear search to restore the full view.
