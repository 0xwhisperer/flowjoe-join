Learn how to work with Joe to automate structural edits and clean up a cluttered project hierarchy.

---

## Workflow Steps

### Step 1: Open Your Target Branch
Select a node that has become disorganized (e.g. containing 20 loose sibling nodes with files attached). **Limit map to my location** (on by default) then gives Joe this branch instead of the whole tree, which keeps the send smaller. See [Token usage with Joe](/joe/token-usage).

### Step 2: Request a Restructure
1. Press `Cmd+Shift+A` / `Ctrl+Shift+A` to open the Joe panel.
2. Ask Joe: *"Review my current branch. Group these 20 sibling nodes into three logical child folders based on their content types, and move the nodes into place."*

### Step 3: Review the Proposal Card
1. Joe processes the hierarchy and returns a **Proposal Card**.
2. Inspect the card. You will see green `+` indicators showing the three new child nodes Joe wants to create, and move indicators showing where original nodes are going.
3. Click **Approve**. The changes apply instantly.

### Step 4: Add a Scheduled Task
1. Ask Joe: *"Every Friday at 4 PM, check this folder for any new nodes, tag them as 'unassigned', and write a summary card."*
2. Approve the schedule card. A clock icon appears on the parent node, indicating a background task is running.
