# flowjoe-join

Static files served at https://join.flowjoe.app (GitHub Pages): the FlowJoe guest app a visitor opens from an owner's invitation link (`https://join.flowjoe.app/#h=<owner>&s=<secret>`).

Everything here except this README is generated — built and published from the FlowJoe app repo by `scripts/build-join-site-app.js` and `scripts/deploy-join-site.js` (run from that repo; the deploy is a dry run unless `--push` is passed). Do not edit the generated files in this repository: change the app repo and redeploy. Do not put secrets here.
