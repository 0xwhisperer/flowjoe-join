Temporary Browser Roadmap Notes

Remove this card before production. These are the known browser-document alignment items that are still planned or intentionally scoped.

Start page / browser gallery dashboard: The docs describe flowjoe://start style ideas, but code still does not implement a real custom start page. New-tab gallery behavior is effectively placeholder/future.

Per-site permission controls: Remote page permissions are denied by default. There is no UI or allow-list for camera, microphone, location, notifications, etc.

Full download manager: Save-location prompting and download notifications exist. A full downloads shelf/manager with progress history, retry, and recent downloads does not.

Session restore UI: Browser sessions are recorded, including crash bookkeeping, but there is no UI to restore a previous session or surface last/crashed sessions.

Clear website data is scoped: It clears storage for origins FlowJoe knows from saved browser records, plus cache. It does not scan every possible Chromium storage origin that may exist only in Electron's profile.

maxOpenLiveViews is not enforced: The setting exists conceptually, but there is no automatic cap that unloads or sleeps live browser views once the limit is exceeded.

Future browser features remain future: Private/incognito tabs, extension support, schema migrations, richer browser history/start-page surfaces, and deeper site-data controls are not implemented.

When a Joe chat runs long (context in the red), FlowJoe automatically summarizes the older turns into a local compacted memory after Joe replies, so the chat stays affordable and within the model's limit. If a send would exceed the hard model limit, FlowJoe may compact first to protect the request. This memory lives only in FlowJoe — it is not OpenAI/ChatGPT memory. Your full conversation stays saved; you can View, Edit, Regenerate, or Delete it. On by default — manual Compact is always available. A summary you've edited is never auto-overwritten.

When you send an image or document to Joe, FlowJoe derives a durable text memory of it so its details survive compaction without resending the file. Turning this off only stops new memories from being created — existing memories are kept and still sent with compacted memory. Default on.

A link card shows a preview of its page, which means the page is contacted the moment the card appears. Cards you add yourself always load their preview. Before each message, a quick AI read decides what Joe actually needs — so casual chats and questions stay light, while his heavier tools and reference load only when a message calls for them. The trade-off is a short pause before Joe replies, in exchange for a leaner, sharper Joe. If the read fails (or no API key is set) it quietly falls back to a simple word-based check, so nothing breaks. On by default.

Document Import Policy

Applies to Markdown-copy imports: .csv, .tsv, .odt, .docx, .epub, .rtf, .ods, .odp, .xlsx, .xls when converted, and .scriv. Hidden search-text formats such as PDF, DOC, PPT, Pages, Numbers, and Keynote keep their originals.

Caution: discarding originals can lose layout, embedded media, formulas, comments, and other source content that Markdown cannot preserve.

Keeps imported originals only for files that would otherwise generate a Markdown copy. Existing Markdown and native text files remain editable; non-text originals that still need a Markdown copy cannot use Edit Copy while this is on. Some documents that rely on generated Markdown may not be searchable as document text.
